# Working rules for agents on margin-bench

`SPEC.md` is binding. It outranks this file, the README and code comments. Where it is silent, make the smallest defensible choice and add a numbered entry to `DECISIONS.md`.

1. **Frozen tests.** Files listed in `tests/FROZEN.txt` are never edited or deleted. `python -m pytest -q` fails if one changes. To correct a frozen test, add a new test, note it in `DECISIONS.md`, and mark the old one xfail only through `tests/XFAIL_REASONS.txt`.
2. **Information boundary.** `src/marginbench/policies/` never imports `environment/`, `economics/` or `evaluation/`. Policies see only the allowlisted `Observation`. A new state field needs a visibility class in `environment/state.py`; a new observation field needs an allowlist entry in `environment/observations.py`.
3. **Locked evaluation.** `configs/plan.yaml` was committed as `prereg: plan v1`. Do not change policies, the estimator (`models/estimator_v1.json`), environment parameters, metric definitions, sample sizes or the primary contrast. Any such change is a new experiment version with a new plan. `marginbench evaluate` and `experiment` refuse to run on a dirty tree or a changed plan or estimator.
4. **Numbers.** Every number in a document comes from a results artifact. `CLAIMS.md` and `RESULTS_SUMMARY.md` are generated by `marginbench report --results results/primary --output .`; never hand-edit them.
5. **Determinism.** No global RNG and no `hash()`. All randomness goes through `environment/randomness.py` keyed streams. Parallel runs must stay byte-identical to serial (`tests/integration/test_parallel.py`).
6. **Before you push:** `python -m pytest -q`, then `marginbench smoke`. After any results change: `marginbench audit --results results`.
7. **Commits.** Small commits on the working branch; results directories are committed, traces (`results/**/traces/`) are not (their hashes are in `replications.jsonl`).
